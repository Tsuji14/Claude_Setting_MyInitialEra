# How to show Update histories 
  1. The version is three numbers, MAJOR.MINOR.PATCH, and which one you raise tells people what changed:

    PATCH (1.0.0 → 1.0.1) - a bug fix; nothing else changes for users
    MINOR (1.0.0 → 1.1.0) - a new feature, added without breaking what's there
    MAJOR (1.0.0 → 2.0.0) - a breaking change; something now works differently than before
    That signal lets people update with confidence - a PATCH is safe to take, a MAJOR means read the notes first.
